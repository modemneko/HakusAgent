## 工作流程

### 1. 拆分粒度

| 太粗 | 恰好 | 太细 |
|---|---|---|
| "做完整套动画" | "开发 Page03 - 数据图表页" | "写 Page03 第 12 行的 interpolate" |
| > 500 行 | 100-300 行 | < 30 行 |
| 难测试 | 可独立验证 | 上下文切换成本高 |

黄金法则：**一个子任务 = 一个可独立运行和验证的功能单元**。

### 2. 拆分顺序

```
Phase 0: 框架搭建  → 主智能体直接完成（不需要子Agent）
Phase 1~N: 逐功能开发  → 每个功能走完整的 开发-测试 循环
Phase Last: 整体集成测试
```

### 3. 依赖关系

- 任务 B 依赖 A → A 必须先 PASS
- 公共组件（主题/工具/配置）放 Phase 0
- 发现新依赖 → 暂停当前任务，先完成依赖
